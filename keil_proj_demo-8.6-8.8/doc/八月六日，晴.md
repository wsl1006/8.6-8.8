1. git init   #创建库
2. git add .   #将文件暂存
3. git commit -m "自己给改变起名字"  #保存版本记录并命名
4. git branch     #检查已有分支
5. git checkout  分支名  #换分支
6. git checkout -b 分支名#创建分支并且切换至该分支
7. git log   #查看日志
8. [git]() diff main feature-blink  #查看两分支区别
9. git  merge feature-blink   #把分支合并到当前分支
10. git reset --hard HEAD~1 #回退

|      git commit -m      |    保存版本记录并命名    | 修改好代码准备存档 |
| :---------------------: | :----------------------: | :----------------: |
|     git checkout -b     | 创建分支并且切换至该分支 |  需要写分支的时候  |
| git reset --hard HEAD~1 |     回退到上一个版本     |    写炸了的时候    |





```c
git checkout main
git log --oneline
git diff main feature-blink
git merge feature-blink
```
